# Company figures and SAUTER product names: a check list, not app data.
#
# Everything under company/ is website marketing copy and background, never an
# app value (CLAUDE.md; company/README.md "Figures: no" and "Product
# identifiers: not yet"; guardrails rule 1 and G1-12). Prompt 3 section 7:
# "Never copy a figure ... from company/". Rule 1: SAUTER model numbers,
# product names and product lines come only from reference data, and gate
# dataset-sauter-catalogue is closed: "No SAUTER product line, product or model
# name anywhere" (G1-3, G2-5). Imports from company/ are blocked by
# dependency-cruiser; tools/checks/company-figures fails when an entry below is
# typed by hand into apps/, packages/*/src, services/extractor/src, a seed or a
# demo fixture (the mockup-figure scope). Nothing imports this file.
#
# One entry per line: kind | figure as written | company/<file>:<line>  # note
#   number    the value in any number format (34,500 34.500 34500 34 500 34_500 34.5k)
#   quantity  the value followed by its unit or word (6.1 years, 38%, 18 EUR/m²)
#   text      the words, ignoring case, diacritics and spacing
#   product   a product or model name as whole words, ignoring case, with up
#             to three spaces, hyphens, dots, slashes, colons or underscores
#             between its letter and digit groups, or none where letters meet
#             digits (EY-RU 310 is also EY-RU310 and ey ru-310)
# Figures are written in English number format; the cited line may use the
# Romanian one. The check never reads company/ (build-readiness decision 12),
# so the cited lines are not re-read at run time: they were checked once, on
# 2026-09-25, when this list was built, by finding each entry on its cited
# line with the check's own matcher. The self-test plants every entry in a
# temporary tree and requires each to be found.
#
# Left out on purpose, as too common to find without flagging ordinary code:
# round percentages and durations (20%, 35%, 40%, 2 ani, 24 months, 4 hours),
# counts under 3 digits, bare 3- and 4-letter model families (DSA, VUL, BUS;
# listed as "SAUTER <code>" instead, except the English words BUT, BUS, BUG,
# DEF and BUN), generic product descriptions (room thermostat), people's
# names, phone numbers and e-mail addresses, figures whose first source is a
# public standard, statistic or law (EN ISO 52120-1 factors, Eurostat prices,
# the 290 kW and 70 kW thresholds of Legea 372/2005 and Directive 2024/1275),
# which reach the app only through an approved reference dataset, and the
# unmerged branch's figures that repeat these. A removal lets more through and
# is a loosening (guardrails section 10).
